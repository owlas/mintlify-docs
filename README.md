# Rainbow Machine docs

Public documentation for Rainbow Machine, built with [Mintlify](https://mintlify.com).

## Preview locally

```bash
npm i -g mint
mint dev
```

Open `http://localhost:3000`.

## Layout

- `index.mdx`, `quickstart.mdx`: getting started.
- `guides/`: task pages for developers and repo owners.
- `reference/`: the `rainbow.toml` schema and the MCP tools.
- `docs.json`: navigation and site settings.

Pushing to `main` deploys.
